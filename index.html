店雷达1688skill
选品与开发

Skill 是给 AI 预装的「操作手册」，可通过压缩包手动安装或发下载链接到对话自动安装，触发方式有两种——在对话中手动引用技能（如 /技能名），或根据提问意图自动匹配触发（如聊到 1688 选品、找货源、热销榜时自动触发店雷达技能），店雷达技能即通过 MCP 调取 1688 真实数据，实现商品搜索、热销榜单、单品分析、图片找货等选品功能。

主要功能

1. 零门槛接入：首次对话自动检测配置状态，未配置 MCP 时自动发送配置教程，或直接帮你一键完成配置，无需手动折腾。

2. 自动连接店雷达：对话引用技能包后自动调取已配置的店雷达 MCP，无需任何额外指令。

3. 默认百条数据：未指定数量时，默认获取 100 条商品数据（店雷达官方单次上限），一次查够看全；你指定数量时则严格按你的要求获取。

4. HTML 可视化交付：查询结果自动生成可视化的 HTML 商品页面，告别密密麻麻的纯文字表格。

5. 内置工具说明书：技能包预先标注店雷达完整工具目录及各工具适用场景，AI 选工具、调接口更精准，问得准、答得对。

6. 主图+链接强输出：商品列表查询强制附带商品主图与商品链接，所选商品一目了然，点开直达详情。

7. 省点规则内置：通过文本规则约束 AI 的调用条件，查过的数据不重复扣点，在不影响体验的前提下让每一点都花在刀刃上。

8. 点数消耗可追溯：每次对话结束自动列出本次调用了哪些店雷达工具、各消耗多少点，点数去向清清楚楚。

9. 自动更新保新：每次对话自动校验技能包版本，版本过低时提示是否更新，同意后自动下载最新版，功能永不过期。
